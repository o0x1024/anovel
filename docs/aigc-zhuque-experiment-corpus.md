# 朱雀实验语料对齐边界

`docs/experiments/` 不是同质数据集。当前将有完整朱雀三分类记录的样本分成四层，机器可读清单位于 `scripts/zhuque-experiment-corpus.ts`。

| 层级 | 用途 | 当前数量 | 约束 |
|---|---:|---:|---|
| calibration | 调整检测参数 | 9 | 可读、完整三分类；属于历史校准集 |
| holdout | 调参后的独立评估 | 20 | 不参与参数搜索 |
| blind | 发布前外部反例 | 1 | 不得进入拟合 |
| robustness_only | 观察朱雀对乱序文本的行为 | 2 | 不可读，不得改变生产检测权重 |

## 监督模型基线

复现命令：

```bash
npm run evaluate:zhuque-supervised -- /path/to/model.onnx /path/to/tokenizer.json
```

朱雀三分类先投影为连续风险：`AI特征 + 0.5 × 疑似AI`。2026-07-19 的本地 INT8 模型实测结果：

- 原始风险 MAE：校准集 37.6，留出集 39.0，B1 盲测 19.1；
- 在校准集搜索最佳仿射映射后，校准 MAE 仍为 24.2，留出 MAE 为 22.2；
- 模型对 M3、M6、G4、B1 给出有效 AI 正证据，但对 A2、G3、M2 等朱雀 100% AI 文本只给出约 3%–9% AI；
- 因而该模型不能作为对称概率与原统计风险固定加权。

生产融合采用单向增证：监督 AI 概率达到 45% 且高于统计风险时，以 60% 权重抬高风险；低分只表示该模型没有命中，不得降低统计检测已有风险。这个决策来自留出集的实际误差结构，不把不可读乱序样本纳入拟合。

2026-07-19 新一轮朱雀在线实测进一步确认三分类边界：词语可预测性 70.6、71.2、81.4 的三条文本均为朱雀疑似AI 100%，95.6、95.7 的 A2 同源文本均为朱雀AI特征 100%。当前先以90作为二者之间的保守门槛：未达到90时，本地高风险只能进入疑似AI；达到90时，非人工片段中的疑似AI并入AI特征，人工片段不动。该门槛需要继续用冻结文本单变量复测，不作为已完成的泛化结论。

同日使用本机 Qwen3.5-0.8B 对原 12 条历史校准记录重新计算，已知字段平均 MAE 为 1.1%。其中 A1、A2、H1、F8、G1、G3、M4、WS4 完全一致，Q6 为 4.2%，K4 为 1.6%。监督模型的单向增证保留这条已验证的统计主链，不用监督低分覆盖它。

## 新实验录入要求

新增样本必须同时保存原文、朱雀三分类、实测日期和用途层级。只有完整标签可以计算三分类误差；同一条样本不能同时出现在 calibration 与 holdout/blind。历史文档中未测、只记录人工占比、三分类相加不等于 100 的记录不进入当前语料清单。
